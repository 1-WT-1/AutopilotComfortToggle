# Autopilot Comfort Limiter Toggle

> [!WARNING]
> HevLib is required for this mod to function.
> A download can be found from its [releases page](https://github.com/rwqfsfasxc100/HevLib/releases/latest)

Adds an in-game tuning toggle under Autopilot to disable acceleration comfort limits, allowing any ship to maneuver with full thruster authority in permanent performance mode.
